## Featured Project

### [Unified AI System](https://github.com/happy520ai/unified-ai-system)

An open, local-first AI gateway for multi-model routing, governed agents,
knowledge, tools, and human-controlled automation.

- One gateway for models, agents, knowledge, tools, and automation.
- Credential-free local startup with a deterministic fake provider.
- Explicit approvals, evidence, observability, and real-provider opt-in.
- Apache-2.0, public container, Linux CI, and reproducible clone verification.
